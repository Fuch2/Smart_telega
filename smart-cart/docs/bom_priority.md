# Приоритет компонентов по BOM

SmartCart может назначать приоритет материалам по частоте использования
`PartNumber` в спецификации платы.

## Правило 50/35/15

Алгоритм считает, сколько раз каждый `PartNumber` используется на плате, затем
сортирует компоненты по убыванию количества.

```text
Priority 1: первые 50% общего количества установок
Priority 2: следующие 35% общего количества установок
Priority 3: оставшиеся 15% общего количества установок
```

Если один `PartNumber` пересекает границу процента, он целиком остаётся в той
группе, в которой начался. Компонент нельзя разделить между приоритетами.

## Как считается количество

Если в BOM есть колонка `Quantity`, используется она.

Если `Quantity` нет, количество считается по `Designator`:

```text
R51-R75     -> 25
R201-R203   -> 3
D8, D9      -> 2
```

## Штрихкод со склада

В заказе хранится отдельное поле `part_number`. При сканировании катушки
сканированная строка считается подходящей, если:

```text
barcode == scanned
part_number == scanned
scanned содержит part_number
```

Пример:

```text
PartNumber в заказе: R03015_1k
Скан со склада:     BOX-77|PN=R03015_1k|LOT=42
Результат:          материал принят
```

## Загрузка BOM в приложении

В UI можно выбрать BOM Excel напрямую через кнопку `Загрузить заказ`.
Поддерживаются файлы:

```text
*.xlsx
*.xls
```

Приложение само создаёт внутренний JSON заказа и импортирует его в workflow.
Ручная конвертация нужна только для диагностики.

## Ручная конвертация Excel BOM в JSON заказа

Инструмент:

```bash
tools/bom_to_order_json.py input.xlsx output.json --order-id ORDER-001 --title "Demo order"
```

На выходе получается JSON:

```json
{
  "order_id": "ORDER-001",
  "title": "Demo order",
  "priority": "normal",
  "duration_minutes": 0,
  "items": [
    {
      "barcode": "R03015_1k",
      "part_number": "R03015_1k",
      "material_type": "reel",
      "required_quantity": 20,
      "usage_priority": 2,
      "target_slot": 6
    }
  ]
}
```

Файл должен содержать колонку `PartNumber`. Если такой колонки нет, конвертер
останавливается, потому что нельзя безопасно определить производственный номер
компонента.
